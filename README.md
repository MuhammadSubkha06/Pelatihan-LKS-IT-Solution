
🌴 Namatara: Tourism Training Platform
Tentang Namatara
Namatara adalah aplikasi platform pelatihan yang dikembangkan khusus untuk mendukung kompetisi LKS (Lomba Kompetensi Siswa). Dengan mengangkat tema Pariwisata, aplikasi ini berfungsi sebagai jembatan digital bagi para calon tenaga profesional di bidang pariwisata untuk mengasah kemampuan mereka melalui materi terstruktur, simulasi reservasi, dan manajemen destinasi.

Nama "Namatara" diambil dari filosofi keindahan nusantara, mencerminkan visi untuk memajukan pariwisata lokal melalui teknologi informasi.
